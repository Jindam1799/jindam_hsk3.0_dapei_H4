# 단어가 말로 이어지는 HSK 4급 짝꿍어휘 · 모바일&PC 단어장

HSK 3.0 4급 필수 어휘 1000개를 단어마다 짝꿍어휘 3개와 함께, **책과 같은 쪽**으로 펼쳐 보는 웹 단어장입니다.
**덩어리로 익히면, 중국어가 툭!** — 진담중국어

HSK 1-2급 단어장(`jindam_hsk3.0_dapei_H1-2`)과 같은 틀이에요. 색과 캐릭터만 4급 것(초록 #047857 · 키위 짝꿍)을 써요.

## 화면 구성
- **인트로**: 키위 짝꿍이 4급 색 문 앞에서 손을 흔들고, 짝꿍어휘가 둥실둥실. "아무 키나 눌러 주세요"(터치해도 시작)
- **📖 책**: 한 화면 = 책 한 쪽(5단어). 0001–0005가 10쪽, 마지막 0996–1000가 209쪽. 구간(20개, 50단어씩) 첫 쪽에 구간 띠(시작한 날 자동 기록), 마지막 쪽에 '구간 완주!'
  - 번호 아래 **□□□ 기억 칸**, 크림색 상자에 짝꿍어휘 ①②③(오늘의 단어는 강조색)
  - 쪽 넘기기: ◀ ▶, 옆으로 밀기, 키보드 ←→ · 가운데 '— 10 —' → 구간 바로가기, 쪽 번호나 단어 번호(예: 0007 → 按时가 있는 11쪽)로 이동
- **아래 버튼**: [汉 한자만 | ⚡ 즉시반응 | 가 한국어만]
  - **汉 한자만**: 누르는 동안 병음·뜻을 가림 → 한자 보고 뜻 떠올리기(중→한)
  - **가 한국어만**: 누르는 동안 한자·병음을 가림 → 뜻 보고 중국어로 말하기(한→중, 즉시반응 연습)
  - 손을 떼면 정답. 화면 아무 곳 꾹 누르기·PC 스페이스바는 마지막에 쓴 방식을 따름
  - **⚡ 즉시반응**: 이 쪽 5단어 / 구간 50단어. 짝꿍어휘가 소리 또는 한국어 뜻으로 나오고 3초(2·1초로 바꿀 수 있음) 안에 말하기. 한 번에 말하면 칸이 채워지고, 못 하면 같은 표현을 다시 + '모르는 단어'에 담김
- **①②③ 톡** → 발음 · **단어 톡** → 팝업(발음, 모름, □ 기억해 냈어요, 짝꿍어휘 테스트, 내 문장 쓰기)
- **□□□ 3칸 = 서로 다른 날 3번 기억해 냄**: 첫날 → 1일 뒤 → 3일 뒤(직전 칸 기준). 오늘 채운 칸은 다시 누르면 취소
- **오늘 복습** 탭: 모르는 단어 먼저 → 다음 칸을 채울 날이 된 단어 · **모르는 단어** 탭
- **진도표**: 외운 단어·3칸 완료·오늘 복습 수, 구간별 1·2·3회 공부한 날(톡하면 오늘 날짜), 키위(□칸 채운 만큼 익음)
- **공부법**: 이렇게 공부해요(마인드 세팅 · 하루 공부 순서 · 3칸 복습) + 앱 사용법, 처음 들어오면 한 번 열림
- **발음(TTS)**: 여자 목소리 Tingting(婷婷) 우선 → 없으면 다른 여자 중국어 목소리, 남자 목소리 제외
- **카카오톡·SNS에서 링크를 열면** 크롬으로 자동 이동(안드로이드 크롬, 아이폰 크롬 → 카카오톡은 안 되면 사파리). 그래도 안 되면 '크롬으로 열어 주세요' 안내
- **링크 미리보기**: `og-kiwi.png`

## 예전 카드형 단어장 기록
예전 단어장(카드 넘기기)에서 쓰던 기록(`hsk4:` 저장값)은 처음 열 때 한 번 자동으로 옮겨 와요.
- 체크 칸 → □□□ 칸(마지막으로 칸이 바뀐 날 기준), ❌ 다시 볼 단어 → 모르는 단어, 보던 구간 → 그 구간 첫 쪽, 연습 방향 → 한자만/한국어만
- 새 기록은 `jindam-hsk4-book-v1`에 저장돼요. 예전 기록은 지우지 않아요.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면·디자인·동작 전부(한 파일) |
| `data.js` | 단어 데이터 (자동 생성 — 직접 고치지 않기) |

| `img/` | 홈 화면 아이콘·파비콘·표지 그림 |

| `tools/build_data.py` | `tools/words/*.txt` → `data.js` 변환기 |

## 단어 고치기
`tools/words/` 안의 txt 파일에서 해당 줄을 고친 뒤 변환기를 실행합니다. 한 줄이 단어 하나이고, `|`로 13칸을 나눕니다.

```
번호|단어|병음|뜻|짝꿍1|병음1|뜻1|짝꿍2|병음2|뜻2|짝꿍3|병음3|뜻3
7|按时|ànshí|제때에|按时完成|ànshí wánchéng|제때에 완성하다|按时到达|ànshí dàodá|제시간에 도착하다|按时吃药|ànshí chī yào|제때에 약을 먹다
```

```
python3 tools/build_data.py
```

## GitHub Pages 배포
1. 이 파일들을 `main` 브랜치에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 후 `https://<계정>.github.io/jindam_hsk3.0_dapei_H4/` 에서 열립니다.
